Methods, limitations & provenance

Spatial query: OBIS occurrence search within WGS84 rectangle longitude −93 to −88, latitude −2 to 2. This is a geographic study window, not a marine ecological boundary.

OBIS: api.obis.org. Requests up to 1,000 records (first result page, no pagination). The actual returned record count and any reported total appear above. The resulting sample is not representative and should not be used for richness comparisons or absence claims.

Boundaries: ArcGIS FeatureServer layers 14 (Áreas Marinas Protegidas) and 13 (Reserva Marina Hermandad), from Haase_Galapagos_Guava_MAP3I_WFL1. These are secondary public hosted layers and are not validated authoritative/legal boundaries. Publication metadata reports last edits in 2023 for layer 14; currency of geometry cannot be guaranteed.

Reproducibility: This self-contained HTML preserves exact endpoints and query parameters, but does not embed a downloaded data snapshot. Loading it again may yield changed data. Runtime API errors and zero features are surfaced, never replaced by simulated content.

Interpretation: Sampling effort, survey methods, geolocation precision, taxonomic verification, and reporting bias vary. An observation plotted inside a polygon does not by itself establish conservation effectiveness. Do not use these geometries for maritime navigation or compliance.
